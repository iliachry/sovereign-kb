# Cognitive & Working Style

## 1. Flow Conditions vs. Cognitive Friction
- **High-Flow Modes**: Deep mathematical modeling, sovereign infrastructure engineering, spatial/3D systems architecture, and technical/philosophical writing.
- **Primary Friction Source**: Fragmented multi-project context switching and manual administrative toil. By the **Queueing / Retransmission Heuristic** ([[02-operating-system/heuristics-and-mental-models]]), operating a schedule near $\rho \to 1$ causes non-linear delay explosions when interrupted.

## 2. AI Agent Interaction Contract
1. **Concise, High-Signal Communication**: Skip filler prose; ground answers in verifiable code, equations, and file links.
2. **Self-Healing Execution**: Run `./scripts/quality_gate.sh` and fix lint, type, unit-test, or LaTeX build failures autonomously before reporting completion.
3. **Multi-Model Separation of Powers**: Never let the same model context that authored a complex change rubber-stamp its own audit (see [[02-operating-system/autonomous-engineering-framework]]).
